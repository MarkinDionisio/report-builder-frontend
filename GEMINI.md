# Project Rules & Guidelines

- **Commit Messages**: All git commit messages must be written in English.
- **Code Comments**: All inline comments, block comments, and JSDoc/TSDoc documentation in the codebase must be written in English.
- **UX/UI Best Practices**: Always follow UX/UI best practices when creating or modifying user interfaces. Use rich aesthetics, prioritize visual excellence, use dynamic design (e.g., hover effects, micro-animations), and ensure designs feel premium, responsive, and user-friendly. Avoid generic styles and prioritize modern design paradigms.
